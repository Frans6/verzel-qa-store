# BUG-002 — API aceita mais de 5 unidades por produto (cálculo e pedido)

| Campo | Valor |
|-------|-------|
| Severidade | Alta |
| Prioridade | Alta |
| Impacto no negócio | Quem chama a API diretamente contorna o limite de 5 unidades por produto (a interface não é a única porta de entrada). Um pedido com 100 unidades é aceito e confirmado. |
| Camada | API (a UI bloqueia corretamente) |
| Critério violado | **CA10** ("máximo de 5 unidades por pedido. A regra vale para a interface **e para a API**") e código `QUANTIDADE_MAXIMA_EXCEDIDA` da tabela de erros |
| Ambiente | https://verzel-store.qa-test-verzel-store.workers.dev/ — v2.3.0 |
| Cenários relacionados | CT-023b, CT-024 |

## Passos para reproduzir
```http
POST /api/carrinho/calcular
{"itens":[{"produtoId":"P004","quantidade":6}]}
```
e
```http
POST /api/pedidos
{"cliente":{"nome":"Maria Silva","email":"maria@exemplo.com","cep":"01310-100"},
 "itens":[{"produtoId":"P004","quantidade":6}]}
```
(repetir com quantidade 100)

## Resultado esperado
`422` com `{"erro":{"codigo":"QUANTIDADE_MAXIMA_EXCEDIDA", ...}}`.

## Resultado obtido
- `/api/carrinho/calcular` → **200** com `quantidade: 6`, total R$ 299,40.
- `/api/pedidos` → **201** com número de pedido (VZ-523638). Com 100 unidades: **201**, total R$ 4.990,00.
- Com 5 unidades o comportamento está correto (200/201), então a validação do limite não existe ou está com a comparação errada.
- Efeito colateral: acima de 5 unidades a regra de frete e cupom também é aplicada normalmente, então a regra de negócio pode ser burlada chamando a API diretamente.

- Quantidades gigantes também passam: `1e21` retorna 200 com subtotal `4.99e+22`, e `1e1` (10) retorna 200.

## Observações
A UI limita em 5 (botões desabilitados), mas o limite parece ser só do lado do cliente. A documentação diz que o cálculo é da API, então ela deve ser a fonte da verdade. Os outros erros de quantidade (0, -1, 1.5, "2", null) funcionam. O caso de produto repetido (3+3) é barrado por `ITEM_DUPLICADO`, então não há como somar mais de 5 por esse caminho.
